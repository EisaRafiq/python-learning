# Password Security Checker

A beginner Python project that checks and rates a password's strength and returns user feedback on how to further improve the password.

# Features
- Checks password length
- Checks for numbers, uppercase letters and lowercase letters
- Checks for special characters
- Detects common passwords
- Detects obvious patterns
- Detects repeated characters
- Creates a security score out of 5
- Provides feedback on how to improve the password

# Technology used
  - Python
  - Pycharm

# what I learned
- using "if" statements and loops
- Working with strings and user input
